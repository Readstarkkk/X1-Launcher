X1 Launcher — PC on Mobile

An experimental platform designed to bring PC applications and games to Android.

X1 Launcher is a project focused on exploring ways to run applications and games originally developed for Windows and Linux on Android devices through compatibility technologies, instruction translation, and graphics integration.

The goal is to develop a custom solution focused on performance, compatibility, and ease of use, starting with technical experiments and gradually expanding to other applications and games.

«Status: Planning and technical research. Compatibility and performance have not yet been demonstrated through a working prototype.»

🎯 Goals

- Develop an application compatibility platform for Android.
- Investigate running Windows and Linux software on ARM64 devices.
- Use artificial intelligence to assist with binary analysis, dependency discovery, and API research.
- Explore compatibility solutions for graphics, input, audio, and system libraries.
- Create a simple interface for installing, configuring, and launching compatible applications.
- Expand support to indie PC games, with the necessary permissions where applicable.

🧪 First Experimental Target

The first experimental goal is to investigate the feasibility of running Roblox Studio on Android.

The research includes:

- Analyzing the application's architecture and dependencies.
- Investigating the Windows APIs used by the software.
- Exploring compatibility with ARM64 processors.
- Researching graphics integration and required libraries.
- Evaluating alternatives for components that are unavailable natively on Android.

Roblox Studio is an experimental target, not an implemented or guaranteed feature.

⚙️ Technical Direction

The final architecture has not yet been determined. Current research areas include:

Area| Objective
Instruction translation| Explore running x86/x64 code on ARM64
System compatibility| Implement or integrate APIs required by applications
Graphics| Research Vulkan, OpenGL, and other required graphics interfaces
Dependencies| Identify libraries and system services required by each application
Artificial intelligence| Assist with technical analysis and component development
Android interface| Build an accessible application and game management experience

The final solution may combine existing technologies, custom development, and application-specific adaptations. AI will serve as a development tool, not as a replacement for engineering, testing, or validation.

🗺️ Development Roadmap

- [ ] Phase 1 — Research: Map architectures, dependencies, and Android limitations.
- [ ] Phase 2 — Prototype: Test compatibility components with simple applications.
- [ ] Phase 3 — Runtime: Develop a functional foundation for running compatible software.
- [ ] Phase 4 — Graphics Testing: Investigate rendering, input, and stability.
- [ ] Phase 5 — Complex Target: Evaluate Roblox Studio as a technical experiment.
- [ ] Phase 6 — Android Launcher: Build the interface for managing applications.
- [ ] Phase 7 — Expansion: Explore ports of indie PC games with the required permissions.

The roadmap may change based on research findings and prototype results.

💰 Business Model

The planned business model may include:

- Sales of game ports and adapted game versions.

Monetization will depend on technical feasibility, agreements with rights holders, and the distribution requirements of each product.
